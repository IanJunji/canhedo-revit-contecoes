Organização do Desenho para o Funcionamento da LSP

Para garantir o funcionamento correto das ferramentas, especialmente as de geração e inserção de blocos em sequência, é crucial que o desenho base esteja preparado adequadamente antes de executar os comandos.

Linhas de Base e Divisibilidade

  • A linha de base (eixo) utilizada para gerar pontos com o comando GPR deve representar o alinhamento exato da face da estrutura de contenção.
  • Regra Geral de Divisibilidade: O comprimento total desta linha de base deve ser um múltiplo exato da dimensão do bloco que será utilizado.
    • Exemplo: Se você usará blocos de 2.50 metros de comprimento, a linha de base deve ter um comprimento como 10m, 12.5m, 25m, ou qualquer outro valor divisível por 2.50.
  • Essa preparação garante que o último bloco se encaixe perfeitamente no final do alinhamento, sem sobras ou faltas, evitando retrabalho manual.
  • Existem exceções a esta regra, como em casos de fechamentos de vãos ou ajustes especiais, que podem ser tratados manualmente após a execução da rotina principal.

Visão Geral dos Comandos

Use o comando COMANDOS no AutoCAD para listar todas as ferramentas. Esta seção detalha cada uma delas.

GERAR_PONTOS_REGUA

Alias: GPR

Gera um arquivo .txt com coordenadas de pontos ao longo de curvas, com espaçamento de corda fixo (método da "régua de aço").

COLOCAR_BLOCO_EM_PONTOS_MEDIOS

Alias: CBPM

Insere um bloco no ponto médio de segmentos definidos por um arquivo de coordenadas, alinhando-o automaticamente.

RotacionarGeogrelhas

Alias: RTGG

Rotaciona blocos em 180° e os desloca perpendicularmente à sua nova orientação.

CRIAR_CAMADAS_BLOCO_ESCADINHA

Alias: CBE

Cria cópias de blocos em camadas, formando uma "escadinha" ideal para contenções e taludes.

ALTBLOCOSEQ

Alias: ABS

Altera a altura (Z) de blocos de forma intercalada (um sim, um não), seguindo uma sequência por proximidade.

APAGAR_BLOCOS_INTERCALADOS_INVERSO

Alias: DELBLOCINV

Apaga blocos de forma intercalada (primeiro sim, segundo não, etc.), baseado na proximidade a partir de um bloco inicial.

EXPORTAR_DADOS_BLOCOS

Alias: EXDBLK

Exporta os dados de Ponto de Inserção (X,Y,Z) e Rotação (em Radianos) de blocos selecionados para um arquivo .txt.

Aplicação: Terra Mesh

Fluxo de trabalho recomendado para modelagem de contenções tipo Terra Mesh.

  1. ✍️ Preparação da Linha de Base:

    Ao trabalhar com contenções tipo Terra Mesh, a linha de base para geração de pontos deve seguir as seguintes orientações, sempre considerando a direção do muro:

    • Curvas para a Esquerda: Mantenha o alinhamento original da face do muro como sua linha de base.
    • Curvas para a Direita: A linha de inserção para os blocos deve ser a linha de topo da camada final. Para isso:
      • Defina a elevação na coordenada Z para a camada final do muro.
      • Aplique um offset com o valor do deslocamento total da curva em relação à linha de base original.
      • O comprimento final desta linha offsetada deve ser exatamente divisível pelo tamanho da caixa (bloco) que será utilizada.
  2. 📏 Geração de Pontos:
    Execute o comando GPR (Gerar Pontos Régua) nas linhas de base e topo preparadas.
  3. 🧱 Inserção de Blocos na Base:
    Use o comando CBPM (Colocar Bloco em Pontos Médios) utilizando o arquivo de pontos gerado e o bloco modelo da sua caixa Terra Mesh.
  4. 🗑️ Ajuste Manual dos Blocos:
    Após a inserção, é comum que alguns blocos intermediários (especialmente em curvas apertadas ou onde há transições) fiquem com posições incorretas ou sobrepostas. Apague manualmente esses blocos para limpar o modelo.
  5. 🪜 Criação das Camadas (Escadinha):
    Execute CBE duas vezes:
    • Camadas de Subida: Selecione os blocos da linha de base e configure o comando para SUBIR, definindo o offset horizontal, a altura vertical e a cota Z final desejada.
    • Camadas de Descida: Selecione os blocos da linha de topo (a camada final do muro) e configure o comando para DESCER. Defina os offsets e altura, visando uma cota Z final que cubra a profundidade total do muro.
  6. 📤 Extração de Dados para o Revit:
    Use EXDBLK (Exportar Dados Blocos) para extrair as coordenadas (X,Y,Z) e ângulos de rotação de todos os blocos gerados, em um arquivo de texto. Este arquivo pode ser importado para o Revit para posicionamento de elementos.

Aplicação: Geogrelha

Fluxo de trabalho recomendado para modelar contenções com Geogrelha.

  1. ✍️ Preparação da Linha de Base:

    Para contenções com Geogrelha, as regras de alinhamento e offset são cruciais, e há uma etapa adicional importante:

    • Curvas para a Esquerda: Utilize o alinhamento original da face do muro como linha de base.
    • Curvas para a Direita: A linha de inserção deve ser a linha de topo da camada final. Considere:
      • Defina a elevação na coordenada Z para a camada final do muro.
      • O offset deve ser calculado como: deslocamento total da curva + tamanho da placa.
        • Exemplo: Se o offset total final do bloco é de 0.9 metros e o comprimento da geogrelha é de 8 metros, o offset a ser usado para a linha de inserção será de 0.9 + 8 = 8.9 metros.
      • O comprimento final desta linha offsetada deve ser exatamente divisível pelo tamanho da caixa (bloco) que será utilizada.
    • Passo Pós-Verificação: Após garantir a correção do comprimento, offset e elevação da linha, é obrigatório aplicar o comando REVERSE nesta linha. Isso garante que a orientação da linha esteja correta para a inserção dos blocos, especialmente em curvas.
  2. 📏 Geração de Pontos:
    Execute GPR (Gerar Pontos Régua) nas linhas de base e topo preparadas.
  3. 🧱 Inserção de Blocos na Base:
    Execute CBPM (Colocar Bloco em Pontos Médios) utilizando o arquivo de pontos gerado e o bloco modelo da sua caixa de Geogrelha.
  4. 🗑️ Ajuste Manual dos Blocos:
    Após a inserção, apague manualmente quaisquer blocos intermediários que fiquem incorretos ou sobrepostos.
  5. 🔄 Ajuste de Orientação das Geogrelhas:
    Para as geogrelhas geradas ao longo das linhas que foram previamente ajustadas com o comando REVERSE, selecione todos os blocos correspondentes e execute o comando RTOB (Rotacionar/Offset Bloco). Isso garantirá a correta orientação e deslocamento.
  6. 🪜 Criação de Camadas (Escadinha):
    Execute CBE (Criar Camadas Bloco Escadinha) para SUBIR a partir da base e depois para DESCER a partir do topo, ajustando offsets e altura para cobrir a profundidade total.
  7. 📤 Extração de Dados para o Revit:
    Finalize executando o comando EXDBLK (Exportar Dados Blocos) para gerar o arquivo .txt com X,Y,Z e ângulos para importação no Revit.

Aplicação: Terra Armada

Fluxo de trabalho recomendado para modelar contenções tipo Terra Armada.

  1. ✍️ Preparação da Linha de Base:

    Para contenções tipo Terra Armada, o requisito principal está na preparação da linha que definirá a profundidade da estrutura:

    • Geração da Linha: Crie uma nova linha com um offset com o valor da profundidade do muro. Esta linha servirá como referência para as operações subsequentes.
    • Divisibilidade: É fundamental garantir que todos os segmentos desta linha (e de qualquer linha de base utilizada) sejam divisíveis exatamente pelo segmento definido para os elementos da contenção.
  2. 📏 Geração de Pontos:
    Execute o comando GPR (Gerar Pontos Régua) nas linhas de base preparadas.
  3. 🧱 Inserção dos Blocos (Inteiros e Meio Blocos):
    Execute o comando CBPM (Colocar Bloco em Pontos Médios) duas vezes:
    • Uma vez para o bloco inteiro.
    • Outra vez para o meio bloco.
  4. 🗑️ Ajuste Manual dos Blocos:
    Após a inserção, apague manualmente quaisquer blocos intermediários que apresentem posicionamento incorreto ou sobreposição.
  5. ↕️ Ajuste de Altura (Blocos Inteiros):
    Execute o comando ABS, selecione o primeiro bloco do muro e defina a altura de meio bloco. O comando ajustará automaticamente os blocos seguintes com a alternância de altura necessária.
  6. 🚮 Remoção Intercalada (Meio Blocos):
    Selecione um meio bloco (o primeiro da sequência) e execute o comando DELBLOCINV (Apagar Blocos Intercalados Inverso). Isso removerá os meio blocos que não são necessários na sequência alternada.
  7. 🏗️ Criação do Muro até a Linha de Topo:
    Selecione todos os blocos inteiros e execute o comando CBE (Criar Blocos Empilhados). Isso irá gerar as cópias verticais dos blocos até atingir a linha de topo da contenção.
  8. 📤 Extração de Dados para o Revit:
    Finalmente, execute o comando EXDBLK (Exportar Dados Blocos) para gerar o arquivo .txt com as coordenadas (X,Y,Z) e ângulos para importação no Revit.
